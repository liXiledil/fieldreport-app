# FieldReport

Turns field service job capture into report content, run-data summaries and expense entry sheets. See README.md and docs/plan.md.

- All data in this repo is synthetic. Never commit real customer, unit, or company data.
- Numbers come from code (`fieldreport.turbocell`); prose comes from the model.
- To build a report package interactively, use the `fieldreport` skill (`.claude/skills/fieldreport/SKILL.md`).
- Tests: `pytest`.
