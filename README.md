# FieldReport

Turns a field service engineer's raw job capture (daily notes, TurboCell run exports, receipt photos, site photos) into report content for macro-enabled Word templates, run-data summaries, and an expense entry sheet.

**Status:** early build. All data in this repo is synthetic. See [docs/plan.md](docs/plan.md) for the architecture and roadmap.

## Layout

- `src/fieldreport/turbocell.py`: deterministic analysis of TurboCell CSV exports (stats, event timeline, limit checks). No AI here, so the numbers are exact.
- `sample-data/`: a synthetic combustion inspection job, generated by `sample-data/make_sample.py`.
- `tests/`: pytest suite run against the sample job.

## Quick start

```bash
pip install -e ".[dev]"
pytest
python -m fieldreport.turbocell sample-data/JOB-0001_*/turbocell/RTS_run_2026-11-06.csv
```

AI steps (report drafting, receipt reading, transcription) will need `ANTHROPIC_API_KEY` and `OPENAI_API_KEY`; see `.env.example`.
