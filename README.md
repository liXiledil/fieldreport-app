# FieldReport

Turns a field service engineer's raw job capture (daily notes, TurboCell run exports, receipt photos, site photos) into report content for macro-enabled Word templates, run-data summaries, and an expense entry sheet.

**Status:** early build. All data in this repo is synthetic. See [docs/plan.md](docs/plan.md) for the architecture and roadmap.

## Layout

- `src/fieldreport/turbocell.py`: deterministic analysis of TurboCell CSV exports (stats, event timeline, limit checks). No AI here, so the numbers are exact.
- `src/fieldreport/report.py`: drafts section content for each report template from the notes plus run analysis, with `[CONFIRM: ...]` where information is missing.
- `src/fieldreport/receipts.py`: receipt photos to an expense entry sheet (one row per receipt, in portal field order, with policy flags and suggested file names).
- `src/fieldreport/providers/`: the model provider interface. Claude is the default; set `FIELDREPORT_MODEL` to change the model.
- `src/fieldreport/cli.py`: runs the whole pipeline on one job folder.
- `sample-data/`: a synthetic combustion inspection job, generated by `sample-data/make_sample.py`.
- `tests/`: pytest suite run against the sample job.

## Quick start

```bash
pip install -e ".[dev]"
pytest
python -m fieldreport.turbocell sample-data/JOB-0001_*/turbocell/RTS_run_2026-11-06.csv
```

Full pipeline (needs `ANTHROPIC_API_KEY`):

```bash
pip install -e ".[ai]"
python -m fieldreport.cli sample-data/JOB-0001_* sample-data/template_section_map.json
```

Outputs land in the job's `output/` folder: `run_analysis.json`, one `<template>.fields.json` per report template, and `expense_entry_sheet.csv`. Voice transcription (OpenAI) comes in a later step.
