# FieldReport sample data

Everything here is synthetic, generated by `make_sample.py` (fixed seed). It mimics a combustion inspection job: daily voice-note transcripts, a TurboCell-style CSV export of the return-to-service run, 9 receipt images with `_ground_truth.json` for accuracy testing, and a generic report template section map. Deliberate test cases: a [CONFIRM] serial number, a policy flag (alcohol on receipt 7), and a vibration and exhaust-spread peak during the load ramp.
